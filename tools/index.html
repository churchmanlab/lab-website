Tools & protocols

Experimental and computational methods

We develop methods for studying transcription, RNA processing, RNA flow between cellular compartments and mitochondrial gene expression. Published protocols, software and analysis code are available below and on GitHub; post-publication corrections are listed with the corresponding protocol.

GeneWalk

Works out which of a gene's annotated functions are actually relevant in your experimental context, using representation learning on a condition-specific gene network.
